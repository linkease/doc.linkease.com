### 大版本升级
* 由于 25.12 切换了包管理器（`opkg` --> `apk`），不支持从 24.10 保留配置升级（因为 iStoreOS 的保留配置升级实际上也保留软件包），所以 **25.12 更新通知不会推送到老版本**（包括 24.10），老版本只能手动升级到 25.12。

* 升级前建议先备份，iStore 的 “维护-系统备份” 可以完整备份当前系统的配置和已安装软件包，如果之后要回退到老版本，可以从这里恢复。注意这个备份只适用于相同大版本恢复，例如 24.10.8 的备份可以恢复到 24.10.x，但不能恢复到 25.12.x。

* 如果要真正的“仅保留配置”升级，可以先在 24.10 进后台 “系统”-“备份与更新” 里备份配置文件，然后恢复出厂设置，之后恢复备份（这几步是为了清理掉软件包，只留下配置文件，所以恢复出厂设置以后不要安装任何软件），最后保留配置升级到 25.12 ，这样就不需要重新配置了，但是自己安装的软件都要重新安装（对于从 iStore 安装的软件包可以从 iStore 的维护页面下载已安装列表，之后一键恢复，但不包括手动安装的）。

* nginx 用户注意，恢复备份以后没有 web 服务，无法访问后台，这时可以打开7681端口的 ttyd 终端（例如 http://istoreos.lan:7681/ ），登录以后执行`/etc/init.d/uhttpd start`临时启动 web 服务就能访问后台了。升级到 25.12 以后用同样的方式临时启动 web 服务，然后进后台安装 nginx 插件。

### 其他变化：
1. 内核从 6.6 升级到 6.12
2. Docker 现在在 “服务” 菜单下 “Dockerman JS”
3. x86 新增 i915-sriov 和 xe-sriov 驱动，可以在 系统-杂项设置-驱动 中选择，i915-sriov 通常不用选择，会自动启用。xe-sriov 可能对于最新的Intel显卡（核显或独显）有用。如果 xe-sriov 和 i915-sriov 同时勾选，那么 xe-sriov 会生效（如果不支持会回退到原始的 i915驱动）。注意 xe 驱动默认不支持 HuC 固件，也就不支持低功耗编码，如果切换到 xe 驱动以后发现 Jellyfin 转码/播放失败，那么 Jellyfin 转码设置中将“低功耗”有关的设置关闭。（如果不需要 SR-IOV 且显卡正常使用，那么两个都不用选）
4. Phicomm N1 的 HDMI 已能正常热插拨，不需要像老版本那样必须开机前插上

### 已知问题：
1. FriendlyArm NanoPi R76S LAN 口可能频繁断连（几分钟一次），暂时可以在 “系统-杂项设置-驱动” 中勾选 r8125 驱动并重启缓解此问题
2. “Dockerman JS” 目前没有一键升级容器的功能（也就是拉取最新镜像并重新部署容器）。如果要升级容器，可以先将容器改名并停止，然后“复制/编辑”，使用原来的名称部署
