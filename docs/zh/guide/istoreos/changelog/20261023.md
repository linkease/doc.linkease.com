### 小版本升级
OpenWRT 版本从 25.12.5 升级到 25.12.6。
包含多个漏洞修复，建议尽快升级。

OpenWRT 25.12.6 发布日志在此查看 https://github.com/openwrt/openwrt/releases/tag/v25.12.6

* 安全修复： 修复大量安全漏洞，涉及 Web 服务、加密组件、Wi-Fi 及 Linux 内核等。
* Wi-Fi 优化： 调整 WPA3 默认配置，改善部分设备的无线连接兼容性。
* 网络改进： 新增 DHCP 客户端标识选项，修复 PPP 按需拨号、L2TP 数据包分片等问题。
* 核心组件升级： Linux 内核更新至 6.12.112，Wi-Fi 驱动更新至 6.18.55，并升级 OpenSSL 等组件。

### 系统
除了 OpenWRT 25.12.6 带来的漏洞修复外，还吊销了两个高风险 CA 证书，详情可参考 https://emudhra.we-have-a-problem.com/

### 安全提醒
php 最近爆出两个高风险漏洞，如果使用了 php 请在软件包里将 php 相关软件包升级到 8.4.27 以上版本。如果检查所有软件包比较麻烦，可以卸载掉 `php8` 这个软件包，依赖也会被卸载，之后再重新安装需要的软件包
